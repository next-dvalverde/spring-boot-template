# Banco Terminal API

API REST desarrollada en Spring Boot para la gestion de operaciones de cajeros automaticos de una entidad bancaria.

## Tecnologias
- Java 17
- Spring Boot
- Maven
- PostgreSQL

## Funcionalidades
- Consultar movimientos
- Retirar e ingresar dinero
- Transferencias
- Activacin de tarjeta y cambio de PIN

## Com ejecutar

```bash
mvn spring-boot:run
